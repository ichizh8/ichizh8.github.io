Theme 01

Interaction

How interfaces shape the relationship before either side appears to make a decision.

Scope

Interfaces, mental models, trust, reliance, attention, anthropomorphism, intimacy, and adaptation.

An interface is not a neutral window onto a model. It distributes initiative, effort, uncertainty, and authority between the person and the system, and it does so before anyone recognizes that a decision is being made.

Work filed here treats the interface as the unit of analysis rather than the model behind it, and keeps interface effects separate from underlying model capability.

Objects of study

  • Conversational interfaces
  • Affordances and defaults
  • Friction and interruption
  • Mental models
  • Explainability in use
  • Control, initiative, and turn-taking
  • Multimodal interaction
  • Failures that reveal the interface's theory of the user
